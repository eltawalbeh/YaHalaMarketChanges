# Phase 05 - Offer CMS and Offer Wizard

This phase turns the dashboard offer wizard into a structured draft workflow.

## Included

- Offer basics: Arabic/English title, destination, country, duration and validity.
- Pricing: amount, currency and pricing basis.
- Hotel option text and inclusions.
- Review step before creating a draft.
- Explicit draft creation through the existing offers service interface.
- No publishing or destructive delete is introduced.

Copy the files into the same paths in the main project.
